## 👨‍💻 About Me

I'm a **Cloud & DevOps Engineer** based in London, Ontario 🇨🇦, focused on designing infrastructure that's **scalable, automated, and bulletproof**.

My obsession? Making systems so resilient that nobody gets paged at 3AM.

- ☁️ **Multi-cloud practitioner** — AWS (certified), GCP (familiar), Azure (expanding)
- 🏗️ I turn manual, repetitive ops work into elegant **automated pipelines**
- 🔭 Deep into **Kubernetes**, **Terraform IaC**, and **GitOps workflows**
- 🧠 Strong believer in **Infrastructure as Code**, **observability-first design**, and **shift-left reliability**
- 🌍 Based in **London, Canada** — engineering cloud systems with a global mindset
